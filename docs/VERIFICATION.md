# 編集文法 v1 の検証記録

実装・素材確認: 2026-09-08。最終レンダー再確認: 2026-09-09。Windows、Python 3.13、Node.js 22、Remotion 4.0.521。下記はこの環境での実測であり、視聴維持率や人手編集との優劣を証明するものではない。

## 実装した範囲

既存のproject.jsonへ16技法・8パターンを追加した。理由・対象・発話参照・強度・seedを保持し、字幕、画面運動、時間加工、SEへ展開する。全文字幕の本文はline.textを維持し、表示サイズ、語単位の改行、読点後の句、強調と登場を改善した。詳細と互換制約は[演出の契約](EDITING_CONTRACT.md)。

合成fixtureは動くテスト映像、背景plate、実際に透明なPNG、440Hzと1800Hzの検査音を使う。38時点の縮小画像をGit管理した参照と照合する。freezeは同じ画素を保持してから再開し、speed_rampの途中・終端・ショット末尾では、期待した元フレーム82・93・136に対応する画を確認する。前景が演出の前後に消えないことも検査する。

字幕着地に置いた1800HzのSEを、完成AACの周波数成分から確認する。着地直後の20msに音があり、直前・終了後より十分大きいことを検査する。これにより、中間AACで実際に発生していた約42.7msの遅延を検出・修正した。現在はPCMミックスを保持して最後に一度だけAACへ変換する。短いSEのフェードもフレーム単位からサンプル単位へ移した。

最終実測では38時点の参照との最大平均画素差は0.234/255、freeze中の画素差は0.0077/255。着地直後のSE成分は0.772、直前は0.0010、終了後は0.0024だった。詳細はローカルの `projects/editing-fixture-v1/output/editing-regression.json` と `editing-contact.jpg` に保存する。画像参照は芸術的な正解画像ではなく、意図しない描画変化を見つけるためのもの。

## 確認の限界

ブラウザーの音を有効にした再生・区間移動と、実音声の時刻・波形・音量を確認した。この実行環境では音を聞き取れないため、読み違い、声の自然さ、聴感上のSEの強さ、語の強勢との一致は人間の試聴を代替していない。文字時刻のない音声の字幕時刻は比例分割である。

人物の自動追跡・動画マッティングは未導入。parallax/subject_popoutは位置合わせ済みの静止画と透過PNGに対応する。Three.jsの3D、光学フロー補間、分散GPU workerも今回の実装範囲外。400本のコーパス分析、AE/AviUtlの人手作品との盲検比較、再生数の評価は実施していない。
