# 実施した検証

2026-09-07、Windows / Python 3.13 / Remotion 4.0.521 / VOICEVOX 0.25.2で実行。

## 実写サンプル

`examples/create_demo.py`と`examples/water.project.json`から、NASAの実写を使った「ロケットを守る、水の壁」を作成した。

| 項目 | 結果 |
|---|---|
| 実尺 | 24.033333秒、721フレーム |
| 映像 | 1080×1920、30fps、H.264 |
| 音声 | 48kHz、AAC |
| 完成ミックス実測 | −16.13 LUFS、true peak −1.51 dBFS、LRA 1.8 LU |
| 全文デコード | 成功 |
| 現在の原稿・MP4との整合 | ローカル納品前検査に成功 |
| 元素材 | NASAの4K記録映像3本、同じArtemis I打ち上げの別収録の音 |
| 編集 | 10カット、発話に追従する編集点、主役に合わせた縦構図、独立した現場音 |

プレビューの各カットの頭・中・末尾を確認し、柱や空を中心に切り抜いていた箇所を修正。水煙で構造が見えなくなる区間は、放水口が見える早い区間へ変更した。完成版で、末尾に混入した前アングルの1フレームを発見して修正。最終フレームから冒頭へ動作がつながることを画像で確認した。

Press Site版は音声トラックがあっても選択区間のサンプルが無音だった。別のNASA原収録から15秒の音を抽出して差し替えた。この実例を受け、選択した音区間の無音をprepare/buildで警告するようにした。

完成MP4 SHA-256: `ba7416f9fd0f459f47655770261245d6a2fa3514055a7b19c9cbf7f1b438b1df`。
制作物は`projects/demo-water/`に保存し、Gitへ含めない。YouTubeへは投稿していない。

## プログラムの検証

- Python単体テスト19件成功（YouTube非公開指定と既存の納品処理を含む）。
- TypeScriptの型検査成功、構図・カメラ・音量のテスト3件成功。
- `tests/render_smoke.py`で実際にRemotionをレンダー。6フレームの色を検査し、開始位置・倍速・カット境界を確認。3区間の音声RMSで指定区間内だけに音があることを確認。無音素材の警告も確認。
- 録音ナレーションはVOICEVOXを呼ばず、フレームへ丸めた終端で音声を切らないことをテスト。
- 元エンジンのHEADと作業ツリーは変更なし。

## 検証の範囲

画像、時間、音声信号、再現手順を検証した。この実行環境では音声を聴取する入力が利用できず、聴感による最終評価は未実施。再生・確認用HTMLとMP4を保存している。

人間のトップ編集者との比較視聴、複数の題材にわたる品質評価、公開後の視聴維持率検証は未実施。テスト成功や単一サンプルを、それらの達成の証拠とは扱わない。

## ElevenLabs・全文字幕（2026-09-07）

- 既存の環境変数でElevenLabs APIに接続し、日本語Voice LibraryのKojiを声一覧へ追加。checkの声照会成功。
- 8発話をeleven_multilingual_v2のwith-timestampsで実生成。原文とalignmentの全文一致を確認。540×960プレビューは24.7秒。
- 最終品質も1080×1920 / 30fps / 24.7秒でレンダー成功。warningsなし、generated=0 / reused=8で完了。
- 元エンジンの字幕描画・日本語折返しを流用。ずんだもんの緑・白・黒と縁幅は維持。白い水煙上の長い2行字幕を目視し、下端360pxから400px、表示領域190pxから200pxに調整した。
- ブラウザーで音声をミュートせず再生し、カット周辺の抜粋も作成。音声を聴取する入力は利用できず、声質・読みの聴感評価は未実施。
- 配置変更後はgenerated=0 / reused=8。字幕文字時刻・本文欠落・破損キャッシュの回帰テストを含めPython 22件、JavaScript 5件、TypeScript型検査に成功。
- 再現コードはexamples/create_elevenlabs_demo.py。素材と生成音声・MP4はprojects/elevenlabs-preview内だけに保存し、Git対象外。YouTube投稿なし。
